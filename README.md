# Saurav Sharma — Portfolio

Personal resume site. Plain HTML, CSS and JavaScript — no build step.

- `index.html` — the page
- `css/style.css` — design tokens, layout, components (dark + light themes)
- `js/main.js` — theme toggle, mobile menu, scroll reveals, counters
- `Saurav_Sharma_Resume.pdf` — downloadable resume

Deploy: `npx vercel --prod`
